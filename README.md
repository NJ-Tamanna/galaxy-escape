# Galaxy Escape

A 2D arcade-style game built in Processing with Box2DProcessing.

## Highlights

- Object-oriented game architecture
- Inheritance and polymorphism through a shared `SpaceItem` base class
- Dynamic, static, and kinematic Box2D bodies
- Contact-listener based collision handling
- Score, health, and timer systems
- Collectibles, hazards, and a portal-based win condition

## Controls

Use the left and right arrow keys to move the ship. Follow the on-screen instructions to start or restart the game.

## Requirements

- Processing
- Box2D for Processing / Box2DProcessing

## Acknowledgements

The Box2D integration was informed by examples and explanations from Daniel Shiffman's *The Nature of Code*. The project-specific gameplay, mechanics, visuals, state handling, and code organization in this repository were developed for this project.

## How to Run

1. Install [Processing](https://processing.org/download).
2. Install the **Box2D for Processing** library using Processing's Library Manager.
3. Download or clone this repository.
4. Open `GalaxyEscape.pde` in Processing.
5. If Processing asks to create a sketch folder named `GalaxyEscape`, click **OK**.
6. Click **Run** to start the game.
